feat(modernization): implement complete NestJS backend and React frontend

This commit delivers the full modernization of FlightJobs from ASP.NET MVC to:

Backend (NestJS):
- Complete authentication system with JWT and ASP.NET Identity password compatibility
- SQLite database integration using better-sqlite3 with TypeORM
- All core modules: Auth, Users, Jobs, Airlines, Statistics, Challenges
- Entities mapped to legacy database schema (aspnetusers, jobs, airlines, statistics)
- Swagger API documentation with CDN static files
- Services: Distance calculator, Payment calculator, Job management
- DTOs with class-validator for input validation

Frontend (React):
- Complete UI with Tailwind CSS and dark theme
- Layout components: Header, Sidebar, Layout wrapper
- All pages: Dashboard, SearchJobs, MyJobs, Airlines, Profile, Challenges, Leaderboards, Settings
- Redux store with slices for auth, jobs, airlines, statistics
- Protected routes and authentication flow
- API integration with Axios interceptors

Infrastructure:
- Database configuration for SQLite with WAL mode
- Password utilities for ASP.NET Identity compatibility (PBKDF2-SHA1)
- Environment configuration and CORS setup

Documentation:
- Gap Analysis, Implementation Roadmap, Frontend UI Plan
- Backend API Plan, Testing Strategy, Database Migration Strategy
